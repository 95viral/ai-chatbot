## 🎮 How to Use New Features

### Search Your History
1. Go to **History** page
2. Press **Ctrl+K** or click **🔍 Search**
3. Type what you're looking for
4. Results update instantly

### Export Your Chats
1. Go to **History** page
2. Press **Ctrl+E** or click **📥 Export**
3. Text file downloads automatically
4. Open in any text editor

### Toggle Theme
1. Press **Ctrl+T** anywhere
2. Or go to **Profile** → Preferences
3. Click theme button
4. Theme saves automatically

### View Statistics
1. Click **Profile** (👤) in navigation
2. See your statistics:
   - Total messages sent/received
   - Total documents uploaded
   - Sessions tracked
3. View account information

### Copy Messages
1. In History, hover over any message
2. Click **📋** button to copy text
3. Notification confirms copy
4. Paste anywhere with Ctrl+V

### Delete Messages
1. In History, hover over any message
2. Click **🗑️** button to delete
3. Message disappears from view
4. Can view notification of deletion

## 🐛 Troubleshooting

### Features not showing?
1. Hard refresh browser (Ctrl+Shift+R)
2. Clear browser cache
3. Check console for errors
4. Make sure backend is running

### Keyboard shortcuts not working?
1. Try **Cmd** instead of **Ctrl** (Mac)
2. Check if input field is focused
3. Try shortcut on different page

### Theme not saving?
1. Check if localStorage is enabled
2. Try toggling theme again
3. Check browser settings

### Export not working?
1. Check if popup blocker is active
2. Ensure you have history to export
3. Try different browser
