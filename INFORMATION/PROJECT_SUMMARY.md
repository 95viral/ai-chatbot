## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| "API not responding" | Ensure backend is running on port 8000 |
| "Invalid OTP" | Check email, ensure OTP is correct |
| "Login page redirects" | Clear localStorage, ensure token is valid |
| "Chat not working" | Verify authentication token exists |
| "Documents not showing" | Upload a file first |
| "CORS error" | Backend CORS already configured |
| "Styling looks wrong" | Clear browser cache |
| "Functions not working" | Check browser console for errors |
